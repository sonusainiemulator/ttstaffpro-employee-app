# Contributing to Open Core Employee App

First off, thanks for taking the time to contribute!

## How to Contribute

1.  **Fork the repository** on GitHub.
2.  **Clone** your fork locally.
3.  **Create a branch** for your edits (`git checkout -b feature/amazing-feature`).
4.  **Commit** your changes (`git commit -m 'Add some amazing feature'`).
5.  **Push** to your branch (`git push origin feature/amazing-feature`).
6.  **Open a Pull Request**.

## Reporting Bugs

Please use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md) to report bugs. Include as much detail as possible.

## Requesting Features

Please use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md) to suggest new features.
